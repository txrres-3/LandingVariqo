# LandingVariqo

La landing usa `#000000` como fondo global y reserva `#B7B7B7` para la
sección “Nuestra esencia”, con acentos de la bandera colombiana para
jerarquía visual.

La familia declarada para títulos prioriza `"Etna Sans Serif"` si está instalada
localmente, seguida por una pila sans-serif disponible en el sistema. No se
incluye un archivo de Etna ni una URL de descarga: no se encontró una
distribución web verificable y utilizable con licencia en este repositorio.
